# UFPA Editais+

Sistema web para centralização, busca e acompanhamento de editais acadêmicos da Universidade Federal do Pará (UFPA).

## Objetivo

Facilitar o acesso dos estudantes a oportunidades acadêmicas, como bolsas, monitorias, projetos de extensão, iniciação científica, estágios e processos seletivos.

## Problema

Atualmente os editais da UFPA são divulgados em diferentes páginas e canais, dificultando sua localização e acompanhamento pelos estudantes.

## Solução

Uma plataforma única para consultar, pesquisar e acompanhar editais acadêmicos.

## Funcionalidades

### MVP

- Listagem de editais
- Busca por palavras-chave
- Filtro por categoria
- Visualização de detalhes
- Consulta de prazos

## Público-alvo

- Alunos de graduação
- Alunos de pós-graduação
- Professores
- Comunidade acadêmica da UFPA
