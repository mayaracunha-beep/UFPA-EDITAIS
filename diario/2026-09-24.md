# Aula 01 (03/09)

## Objetivo

Definir o problema a ser resolvido e criar a estrutura inicial do projeto UFPA Editais+.

## Ferramenta

GitHub Web e Microsoft Copilot.

## O que o agente entregou

Sugestões de tema, definição do MVP, estrutura inicial do repositório, conteúdo para README.md, SPEC.md e AGENTS.md.

## O que mudamos à mão

Escolha do tema UFPA Editais+, ajustes na descrição do projeto e organização dos arquivos de documentação.

## O que aprendemos

A disciplina exige que a especificação seja criada antes do código. Também aprendemos a organizar um repositório GitHub para documentar o processo de desenvolvimento apoiado por IA.
